# Migration Review Skill 填写模板

> 迁移评审负责人复制本结构填写 `SKILL.md`。尖括号内容必须替换；不适用项写 `N/A` 及原因。  
> 本 Skill 只写迁移评审与回滚做法；具体工具版本引用 Organization Rule / 后端栈约定。  
> 已填写示例：[`EXAMPLE.md`](./EXAMPLE.md)（仅展示粒度，不代表默认技术栈）。

## 1. 元数据

```yaml
---
id: skill.migration-review
version: 1.0.0
status: draft
owner: <迁移/数据评审负责人>
compatibleRoles: [migrationReviewer]
appliesTo:
  paths:
    - <迁移文件路径 glob>
relatedRules:
  - <数据/安全相关 Rule ID>
relatedRiskTriggers:
  - <policies.yaml 中迁移相关标签>
---
```

## 2. 工具、路径与前置条件

```markdown
## 工具与路径

- 迁移工具：`<名称；版本见 Rule/栈约定>`
- 迁移文件路径：`<真实路径/glob>`
- 回滚方式：`<自动 down / 手动剧本 / 备份恢复等>`
- 工作目录：`<执行迁移命令的目录>`
- 环境变量样例：`<示例文件；禁止真实密钥>`

## 前置条件

- 变更/迁移标识：`<ID 规则>`
- 前置备份或恢复点：`<要求>`
- 数据分级已标注；禁止使用未脱敏生产数据做验证
```

## 3. 评审工作流

```markdown
## 评审工作流

1. 确认迁移文件位于规定路径且关联 REQ/契约变更。
2. 评估向前兼容、锁表/长事务与停机窗口需求。
3. 核验回滚剧本可执行，含触发阈值与责任人。
4. 核验数据分级、脱敏与敏感字段处理。
5. 输出批准/修改/阻塞结论与证据路径。
```

## 4. 必查清单

```markdown
## 必查

- [ ] 向前兼容 / 扩展-收缩策略明确
- [ ] 锁表、全表扫描、长事务风险已评估
- [ ] 回滚剧本可执行，含验证步骤
- [ ] 数据分级与脱敏符合安全规则
- [ ] 是否需停机窗口及批准人已声明
- [ ] 与 API 契约破坏性变更流程一致（如适用）
```

## 5. 数据分级

```markdown
## 数据分级

| 数据/能力类别 | 分级 | 允许位置/处理方式 | 禁止行为 | 检查方式 |
|---|---|---|---|---|
| `<类别>` | `<级别>` | `<方式>` | `<禁止>` | `<命令/评审>` |
```

仅写标识与类别，不写秘密或真实生产样本。

```markdown
- 回滚步骤：`<可复制步骤或命令>`
- 数据一致性验证：`<命令或检查项>`

```

## 7. 输出格式

```markdown
## 输出格式

- 结论：`<APPROVE / REQUEST_CHANGES / BLOCK>`
- 迁移文件：`<路径列表>`
- 风险与窗口：`<摘要>`
- 回滚证据：`<路径>`
- 剩余风险：`<无，或仅人类 Owner 可接受的项>`
```

## 8. 激活检查

- [ ] 工具、路径、回滚方式已填写且可执行或有明确 N/A
- [ ] 回滚剧本含触发阈值、步骤、验证与责任角色
- [ ] 数据分级与安全规则一致，无真实密钥
- [ ] Owner 将 `status` 改为 `active`
