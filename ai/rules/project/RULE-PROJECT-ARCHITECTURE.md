# 项目架构约束

> **人类必填**。

## 系统边界

- _待填：本系统负责什么 / 不负责什么_

## 模块关系（摘要）

```text
_待填：模块依赖示意_
```

## 不可破坏约定

- _待填：同步调用禁忌、数据所有权、事件主题命名等_

## ADR 入口

- 目录：`design/decisions/` 或组织规定的 ADR 路径
- 新增破坏性变更必须先有 ADR，状态 `APPROVED` 后方可进开发任务
