## 业务目标

为可信数据空间接入端运营方与数据提供方提供统一 Web 工作台，使其能直观掌握链上资产运营态势，并对数据产品目录进行结构化登记、检索、详情查看与上链溯源。

成功标准（来自 PRD，可观察）：

- P0 路径（登录身份切换 → 总览查看 → 数据目录筛选/检索 → 产品详情 → 上链信息 → 新增/编辑产品并产生链上版本）在 staging 端到端通过；
- 管理员可维护行业一二级分类；提供方可新增/编辑产品；普通用户仅可浏览；
- P0 缺陷为 0。

## 角色与权限摘要

| 角色 | 可观察能力 |
|---|---|
| 管理员（运营管理员） | 浏览总览与目录；维护行业一/二级分类；新增/编辑数据产品 |
| 提供方 | 浏览总览与目录；新增/编辑数据产品；不可维护行业分类 |
| 普通用户 | 浏览总览与目录、产品详情与上链信息；不可新增/编辑产品，不可维护分类 |

> 正式实现须为登录态鉴权；禁止仅靠前端隐藏写入口（见 REQ-RBAC-001）。

## 优先级政策

- `P0`：核心路径与写权限相关能力，缺失则不得按成功标准发布。
- `P1`：本版范围内重要能力，须通过验收（含上链 TOP、资源分布）。

## 关键枚举约束（来自 PRD，实现须一致）

| 维度 | 取值 |
|---|---|
| 产品类型 | 数据集、数据报告、数据接口、其他数据产品 |
| 数据来源 | 自行生产、公开收集、协议取得、衍生创造 |
| 交付方式 | API、文件传输、数据沙箱、隐私保护计算 |
| 更新频率 | 实时、每日、每周、每月、每年、按需 |
| 数据产权类型 | 数据持有权、数据使用权、数据经营权 |
| 地域范围 | 国际、全国、省级、市级、区县级、区县级以下 |
| 数据质量等级 | A级、B级、C级、D级 |

## 非功能约束（来自 PRD，不做技术选型）

- 页面以中文为主；关键操作有明确成功/失败反馈。
- 列表与筛选在常见桌面分辨率可用；图表在窗口变化时可重绘。
- 写操作需鉴权；敏感标识（哈希、DID、信用代码）本版至少完整可读（可截断展示并支持完整复制）。
- 上链适配层可替换：本版允许模拟存证；数据结构须预留 metadataHash / ownerDID / timestamp / certificate.owner（见 DEC-WSC-002）。

## Out of Scope / 非目标

（原样冻结自 PRD）

- **数据登记**完整业务流（菜单占位，本版不交付页面与接口）
- **交易订单**下单、履约、分账（仅总览流中可展示相关上链动态文案）
- **连接器管理**（菜单占位，本版不交付）
- 真实区块链节点接入与链上交易确认（本版可对接存证服务或先做可替换适配层；验收可用模拟哈希/DID）
- 移动端原生 App / 对外公开注册门户
- 多租户隔离与跨企业组织树管理
- 真实支付与计费结算引擎
