## 业务目标

在功能已 VERIFIED 的 V1.1 基线之上，将 `frontend/` 主路径页面的信息架构、视觉呈现与交互质感收敛到 V1.1 原型可验收程度，提升可感知完成度，并建立可追踪的设计令牌与偏差闭环。

成功标准（可观察，UI/UX 对齐）：

- 主路径页面（登录、壳层/侧栏、总览、数据目录、目录维护、分类维护弹窗、产品详情/编辑、批量导入、上链信息）在信息架构与视觉呈现上与原型对齐到可验收程度，无 P0 级「完全不像原型」页面；
- V1.1 已交付功能行为（三角色 RBAC、三级分类、导入、上链等）不回退；
- 设计令牌（色彩、圆角、阴影、字号阶梯等）可对照原型 `:root` 变量追踪；
- 中文界面文案与原型 / V1.1 产品用语一致。

## 角色与权限摘要

与 SNAP-WSC-002 **相同**；本版 **不改变** 权限矩阵，只改变有权页面的呈现与交互质感。

| 角色 | 可观察能力（功能继承，不变） |
|---|---|
| 管理员 | 浏览；维护三级分类；目录维护（关联）；新增/编辑/批量导入产品 |
| 提供方 | 浏览；新增/编辑/批量导入；不可分类维护与目录维护 |
| 普通用户 | 只读浏览总览、目录、详情、上链信息 |

> 鉴权与写 API 规则仍以 SNAP-WSC-002 `REQ-RBAC-001` 为准；本快照不新增权限需求。

## 优先级政策

- `P0`：主路径视觉对齐与功能不回退；缺失则不得按本版成功标准发布。
- `P1`：本版范围内重要呈现/质感能力，须通过验收，但不单独阻塞「不像原型」以外的主路径判定时可排在 P0 之后闭环。

## 非功能约束

- **视觉权威**：`design/prototypes/wsc-v1.1/index.html`（可交互 HTML 原型）。
- **功能与契约权威**：SNAP-WSC-002 + `wsc-contracts@2.0.0`；本 Run **默认不改** OpenAPI、RBAC 矩阵、后端领域模型、Flyway/SQL。
- 中文界面文案与原型 / V1.1 产品用语保持一致。
- 响应式以桌面端为主；明显破坏性窄屏问题可修。
- 图表优先 CSS/配置级对齐；非对齐所必需不替换图表库。
- 开发与审查隔离；并行任务须写集可证明安全（流程约束，非本快照技术选型）。

## Out of Scope / 非目标

- 重做 V1.1 业务功能，或重新打开已关闭的功能缺陷（除非本轮 UX 改造引入回归）。
- 修改 `contracts/**`、后端写路径、Flyway/SQL（默认）；若 UX 验收证明必须扩 scope，须经 PO 批准并新建快照/DEC，不得静默扩大。
- 新开业务能力；数据登记 / 交易订单 / 连接器管理完整业务流（菜单占位策略不变）。
- 移动端原生 App、暗色主题（原型未要求则不做）。
- 用 Ant Design 默认主题「凑合」而未对照原型令牌与布局。
- 真实链共识、公开注册门户、多租户组织树、支付结算引擎（继承 SNAP-WSC-002 非目标）。
