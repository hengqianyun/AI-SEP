## 业务目标

在 V1.0 统一工作台之上，补齐三级分类、目录关联维护与产品批量导入，降低大规模目录运营成本；总览、详情、编辑与上链溯源主路径保持可用。

成功标准（可观察）：

- V1.0 P0 路径仍可通过；
- 管理员可维护「空间 → 行业 → 子类」并对目录条目单条/批量关联；
- 管理员与提供方可批量导入产品（模板 + 结果反馈）；
- P0 缺陷为 0。

## 角色与权限摘要

| 角色 | 可观察能力 |
|---|---|
| 管理员 | 浏览；维护三级分类；目录维护（关联）；新增/编辑/批量导入产品 |
| 提供方 | 浏览；新增/编辑/批量导入；不可分类维护与目录维护 |
| 普通用户 | 只读浏览总览、目录、详情、上链信息 |

> 须登录态鉴权；禁止仅靠前端隐藏（REQ-RBAC-001）。

## 优先级政策

- `P0`：核心路径与写权限相关能力，缺失则不得按成功标准发布。
- `P1`：本版范围内重要能力，须通过验收。

## 关键枚举约束

| 维度 | 取值 |
|---|---|
| 产品类型 | 数据集、数据报告、数据接口、其他数据产品 |
| 数据来源 | 自行生产、公开收集、协议取得、衍生创造 |
| 交付方式 | API、文件传输、数据沙箱、隐私保护计算 |
| 更新频率 | 实时、每日、每周、每月、每年、按需 |
| 数据产权类型 | 数据持有权、数据使用权、数据经营权 |
| 地域范围 | 国际、全国、省级、市级、区县级、区县级以下 |
| 数据质量等级 | A级、B级、C级、D级 |
| 一级分类（空间） | 可配置（原型例：可信空间、航贸数字化） |
| 二级/三级分类 | 可配置，挂在上级之下；产品挂载于三级 |

## 非功能约束

- 页面中文为主；关键操作有成功/失败反馈。
- 列表与筛选桌面可用；图表可重绘。
- 写操作鉴权；敏感标识至少完整可读。
- 上链适配层可替换（DEC-WSC-002）。
- 批量导入有完成反馈；超 10MB 拒绝并提示。
- 滚动加载不得丢失筛选条件。
- 后端栈：Java 17 / Spring Boot 2.7.18 / MySQL / Redis / Flyway（DEC-WSC-004、DEC-WSC-005）。

## Out of Scope / 非目标

- 数据登记 / 交易订单 / 连接器管理完整业务流（菜单占位）
- 真实链共识、移动端 App、公开注册门户、多租户组织树、支付结算引擎
- 导入模板全量类型专属列（本版模板以基础信息为主）
