## 问题与目标

### 要解决的问题

V1.5 目录浏览在产品列表区仍保留「业务视图 / 业务大类」快捷卡片，高级筛选默认收起且含「行业类别」字段；业务视图与业务大类在高级区为独立下拉，交互分散。座序图（CirculationSeatMap）无法按业务视图切换下方统计卡片。用户模型缺少「企业」维度，管理员无法在「我的数据产品」维护本企业产品，目录维护与提供方权限边界需按企业场景重划。

### 成功标准（可观察）

1. **浏览筛选**：列表区无业务视图/业务大类卡片；高级筛选区默认展开且无「高级筛选」开关；高级区无「行业类别」；业务视图→业务大类以 Cascader 联动，查询映射 `l1`/`l2`。
2. **座序图**：标题右侧有业务视图下拉（含「全部」默认）；下方卡片随所选业务视图过滤；不出现企业筛选控件，座序图不按企业过滤。
3. **企业与 RBAC**：用户归属企业；同一企业可有多个 ADMIN；ADMIN 在「我的数据产品」可增改导（同 PROVIDER）；ADMIN 侧栏同时可见「目录维护」（全量）与「我的目录」（本企业）；PROVIDER 仅可见「我的目录」；PROVIDER 不可见「目录维护」；本阶段不展示独立企业管理页，不区分超级管理员与企业管理员。
4. **数据范围**：「我的数据产品」= 本企业产品；「我的目录」中 ADMIN = 本企业目录；「目录维护」（ADMIN）= 全量；「全链数据目录」= 全量（无企业过滤）。
5. **不回退**：V1.5 已发布能力（座序图存在、企业名 `supplierName` 模糊搜、未分类 API 全局置底、Ant Design 控件、目录维护 Pagination/Cascader/全选等）不得削弱；编辑/导入等仍复用 `INDUSTRY_CATEGORY_OPTIONS` 表示行业类别。

## 角色与权限

| 角色 | 全链数据目录 | 座序图 | 我的数据产品 | 我的目录 | 目录维护（侧栏） | 分类维护 | 用户管理 |
|---|---|---|---|---|---|---|---|
| ADMIN | 只读浏览 + 座序图 | 有；可按业务视图筛卡片 | **可**增改导；**本企业**产品 | **有**；范围 **本企业** | **有**；范围 **全量** | 有 | 有 |
| PROVIDER | 只读浏览 + 座序图 | 有；可按业务视图筛卡片 | 增改导；**本企业**产品 | **有**；范围 **本人创建**产品 | **否** | 无 | 无 |
| USER | 只读浏览 + 座序图 | 有 | 不可见 | 不可见 | 不可见 | 无 | 无 |

> **说明**（PO-CONFIRM-011-001）：ADMIN 侧栏同时保留「目录维护」（全量）与「我的目录」（本企业）；PROVIDER 仅「我的目录」，不可见「目录维护」。独立超管后台仍 Out of Scope；本阶段不实现「超级管理员 vs 企业管理员」菜单拆分。ADMIN 在「目录维护」按全局语义操作；在「我的数据产品 / 我的目录」按上表数据范围约束。

## 范围

### In Scope

#### 1. 目录浏览 / 筛选（公共目录与我的数据产品同源）

1.1 移除产品列表区域的「业务视图」「业务大类」筛选卡片（含 active 态标签行）。

1.2 移除「高级筛选」展开/收起按钮；高级筛选面板（`BrowseFilterBar` 或等价区域）**默认可见**。

1.3 高级筛选中**移除「行业类别」**字段；浏览列表请求**不再**携带 `industryCategory` 参数（编辑页、导入映射等仍保留该字段与 `INDUSTRY_CATEGORY_OPTIONS`）。

1.4 将原「行业类型」/分类相关下拉替换为 **Cascader**：一级选项 = 业务视图（L1），二级 = 业务大类（L2）；支持选到 L1 或 L2；映射查询参数 `l1` / `l2`（与既有契约字段对齐）；清空表示不限。

1.5 保留 V1.5 其余高级筛选项：数据来源、产品类型、是否涉及公共数据、交付方式、关键词搜索、企业名称（`supplierName`）等；控件仍为 ant-design-vue。

1.6 未分类全局置底、`supplierName` 模糊搜等行为 **继承 REQ-CAT-012**，不得回退。

#### 2. 座序图（CirculationSeatMap）

2.1 在座序图标题行**右侧**增加下拉框：选项 = 全部业务视图列表 + 默认项「全部」。

2.2 选择某一业务视图后，座序图**下方统计卡片**（L2 Top5 图例/卡片区）仅展示该 L1 下的 L2 分布；选「全部」时行为与 V1.5 一致（全链 Top5）。

2.3 **不得**在座序图区域增加企业筛选 UI；座序图数据**不按登录用户企业**过滤（始终反映公共目录统计口径）。

2.4 保留 V1.5 座序图核心交互：比例座位、hover 熄灭其它域、真实 `totalProducts`；**不**引入点击座序图联动列表筛选（仍 Out of Scope）。

#### 3. 用户 / 企业 / RBAC / 导航

3.1 用户模型引入**企业**归属：每个用户关联一个企业（标识由实现确定，如 `enterpriseId`）；**同一企业可有多名 ADMIN**。

3.2 **ADMIN** 与 **PROVIDER** 均可在「**我的数据产品**」执行新增、编辑、批量导入（与 PROVIDER 相同 UX）；列表范围为 **本企业** 已上架/可见产品（不再仅限 `create_by=本人`）。

3.3 新增侧栏菜单「**我的目录**」：**ADMIN + PROVIDER** 可见；页面布局与交互 **同现「目录维护」页**（Pagination、Cascader 筛选、本页全选、统一维护等，继承 REQ-CAT-013）。

3.4 **PROVIDER** 侧栏 **不得** 出现「目录维护」；仅通过「我的目录」进入维护能力。

3.5 「**目录维护**」菜单 **仅 ADMIN** 可见；数据范围为 **全平台** 产品目录（继承 V1.5 全局维护语义）。独立超管后台仍 Out of Scope；本阶段 **不** 区分超级管理员与企业管理员身份。

3.6 「我的目录」数据范围：**ADMIN** = 本企业数据产品目录；**PROVIDER** = 本人创建（`create_by`）的产品，与 V1.5 目录维护中 PROVIDER 范围一致。

3.7 「**全链数据目录**」展示 **全平台** 产品，**不** 按登录用户企业过滤。

3.8 **本阶段不做** 企业管理页（创建企业、企业列表、企业信息维护等）。

3.9 在编辑、导入、详情等仍需要「行业类别」的场景，**继续复用** 前端 `INDUSTRY_CATEGORY_OPTIONS`（GB/T 门类枚举）；仅浏览高级筛选移除该字段。

### Out of Scope / 非目标

- 企业管理页面（企业 CRUD、企业切换、企业配额等）
- 独立超管后台与本阶段超管/企管菜单拆分（ADMIN 仍保留现有「目录维护」全量入口）
- 座序图按企业过滤或企业筛选 UI
- 座序图点击联动列表 L2 筛选
- 浏览页「行业类别」筛选项（字段在产品上仍可存在）
- 跨页全选统一维护（继承 V1.5 Out of Scope）
- 用户管理功能大改、硬删除、密码重置邮件、OAuth、完整多租户
- Downloads React 仓改造
-  weaken V1.5 已发布：未分类置底、`supplierName` 检索、座序图挂载、mine 页无座序图等
