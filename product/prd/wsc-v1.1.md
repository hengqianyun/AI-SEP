## 问题与目标

- 要解决的问题：在 V1.0 工作台能力之上，补齐**三级分类体系**、**目录关联维护**与**产品批量导入**，降低大规模目录运营成本。
- 成功标准：
  - V1.0 P0 路径仍可通过；
  - 管理员可维护「空间 → 行业 → 子类」三级分类，并对目录条目做单条/批量关联；
  - 管理员与提供方可批量导入产品（模板 + 结果反馈）；
  - P0 缺陷为 0。

## 相对 V1.0 的变更摘要

| 类型 | 内容 |
|---|---|
| 新增 | 侧栏「目录维护」页；批量导入产品；目录列表滚动加载 |
| 变更 | 分类由「一/二级行业」升级为「一级空间 + 二级行业 + 三级子类」；目录浏览改为顶部空间/行业标签 + 子类分组列表 |
| 继承 | 总览、产品详情、编辑、上链信息、三角色 RBAC 主路径；占位菜单仍不交付 |
| 工程 | 新功能以后端 data-chain 骨架为权威（DEC-WSC-005）；V1.0 遗留 `backend/` 仅热修 |

## 范围

### In Scope

- V1.0 In Scope 全部能力（以实现口径随本版分类模型升级为准）
- **三级分类维护**（空间 / 行业 / 子类）
- **目录维护**：待关联 / 已维护状态筛选、单条与批量关联分类、分页
- **批量导入产品**：xlsx/csv、下载模板、导入结果与失败报告
- **数据目录**浏览交互升级（顶部标签 + 子类分组 + 滚动加载更多）

### Out of Scope / 非目标

- **数据登记**完整业务流（菜单占位）
- **交易订单**下单、履约、分账（仅总览流可展示相关文案）
- **连接器管理**（菜单占位）
- 真实区块链节点接入与链上交易确认（仍为可替换存证适配层）
- 移动端原生 App / 对外公开注册门户
- 多租户隔离与跨企业组织树管理
- 真实支付与计费结算引擎
- 导入模板字段的全量类型专属列（V1.1 模板以基础信息字段为主，见 REQ-CAT-008）

## 系统角色

| 角色 | 能力（相对 V1.0 增量加粗） |
|---|---|
| 管理员（运营管理员） | 浏览总览与目录；**维护三级分类**；**目录维护（关联）**；新增/编辑/**批量导入**数据产品 |
| 提供方 | 浏览总览与目录；新增/编辑/**批量导入**数据产品；不可见目录维护菜单与分类维护 |
| 普通用户 | 浏览总览与目录、产品详情与上链信息；无写入口 |

> 正式实现须为登录态鉴权；禁止仅靠前端隐藏写入口。

## 需求

### REQ-SHELL-001 工作台壳层与导航

- 优先级：P0
- 变更：相对 V1.0 **修订**
- 摘要：固定侧栏品牌区、主导航与当前企业信息；主区按模块切换。
- 验收：
  - 侧栏展示「总览」「数据目录」；**管理员可见「目录维护」**；
  - 「数据登记」「交易订单」「连接器管理」可见但点击后明确提示「本版本未开放」或不进入空页误导；
  - 当前企业信息可展示；角色切换后写入口与「目录维护」可见性立即更新。

### REQ-RBAC-001 角色权限控制

- 优先级：P0
- 变更：相对 V1.0 **修订**
- 摘要：按角色控制分类维护、目录维护、新增/编辑/批量导入及对应写接口。
- 验收：
  - 管理员：三级分类维护、目录维护、新增/编辑/批量导入；
  - 提供方：新增/编辑/批量导入；不可见/不可调用分类维护与目录维护；
  - 普通用户：无上述写入口；直接调用写 API 返回 403。

### REQ-OVW-001～005 总览

- 优先级 / 验收：与 V1.0 相同（OVW-001/002/004 为 P0；OVW-003/005 为 P1）。
- 变更：相对 V1.0 **继承**（无行为变更要求）。

### REQ-CAT-001 数据目录浏览结构

- 优先级：P0
- 变更：相对 V1.0 **修订**
- 摘要：按三级分类浏览产品；列表区顶部为空间与行业标签，中部按三级子类分组展示产品，右侧为产品预览。
- 验收：
  - 可切换一级空间标签与二级行业标签，产品集随之更新；
  - 产品按三级子类分节展示（节标题 + 数量）；列表项含序号/编码/名称/上链次数/类型标签；
  - 选中后右侧预览含名称、编码、分类路径（三级）、上链次数、概述及操作按钮；
  - 列表支持滚动加载更多（有「加载中」反馈；加载后保留滚动位置）。

### REQ-CAT-002 多维筛选与搜索

- 优先级：P0
- 变更：相对 V1.0 **修订**（行业筛选项对齐三级模型）
- 摘要：支持组合筛选与关键词搜索。
- 验收：同 V1.0 的数据来源 / 产品类型 / 公共数据 / 交付方式 / 关键词规则；行业分类筛选项须能落到二级或三级（与原型级联一致）；无结果有空态。

### REQ-CAT-003 / REQ-CAT-004 / REQ-CAT-005

- 变更：相对 V1.0 **继承并适配三级分类路径**（详情/编辑中的行业分类展示与必填改为三级路径或等价选择器）。
- 产品编码、上链版本、类型专属字段等验收仍分别遵循 DEC-WSC-001 / DEC-WSC-002 与 V1.0 字段表。

### REQ-CAT-006 维护三级分类

- 优先级：P0
- 变更：相对 V1.0 **修订**（由一/二级升级为三级）
- 摘要：管理员维护一级（空间）、二级（行业）、三级（子类）。
- 验收：
  - 弹窗分栏维护三级；支持新增空间 / 二级 / 三级；有未保存变更时「待保存」提示；
  - 保存后目录浏览标签、筛选与目录维护级联数据更新；取消不落库；
  - 非管理员不可打开；**有挂载产品（或已关联目录）的分类禁止删除**（DEC-WSC-003 延伸至三级）；
  - 至少保留一个三级目录（或原型等价约束：不可删至无可用三级）。

### REQ-CAT-007 目录维护（关联）

- 优先级：P0
- 变更：相对 V1.0 **新增**
- 摘要：管理员在「目录维护」页查看目录条目，将未关联条目关联到三级分类路径，支持单条与批量。
- 验收：
  - 状态页签：全部 / 已维护 / 待关联；
  - 可按一/二/三级分类筛选；列表分页；
  - 条目展示名称、编码、当前路径（未关联显示「未关联」）与状态；
  - 单条「维护」可选择空间/行业/子类并保存；取消不落库；
  - 多选后批量栏展示已选数量，选择目标三级路径后「批量保存」生效；「取消」清空选择；
  - 提供方与普通用户不可进入该页/API。

### REQ-CAT-008 批量导入产品

- 优先级：P0
- 变更：相对 V1.0 **新增**
- 摘要：管理员与提供方通过 Excel/CSV 批量导入产品。
- 验收：
  - 入口对有写权限角色可见；支持拖拽或点击上传；`.xlsx` / `.csv`；单文件 ≤ 10MB；
  - 可下载导入模板（至少含：产品名称、产品编码、产品类型、行业分类、数据来源、更新频率、涉及个人信息、涉及公共数据、交付方式、计费方式、价格等）；
  - 完成后展示结果：成功/失败条数；失败时可下载错误报告（原因至少覆盖：编码重复、分类不匹配、必填缺失）；
  - 支持重新上传；取消/关闭不留下半成品目录状态（失败行不入库或可明确回滚策略并在实现说明中写清）；
  - 导入成功的产品须可在数据目录中检索，并产生上链版本记录（与 REQ-CAT-005 一致，允许批量异步但须可观测完成态）。

### REQ-CHAIN-001 上链信息页

- 优先级：P0
- 变更：相对 V1.0 **继承**（快照字段随三级分类路径展示升级）。

## 关键枚举（实现约束）

与 V1.0 相同。另：

| 维度 | 取值说明 |
|---|---|
| 一级分类（空间） | 如：可信空间、航贸数字化（可配置，非写死枚举） |
| 二级分类（行业） | 挂在某一级下，可配置 |
| 三级分类（子类） | 挂在某二级下，可配置；产品挂载点 |

## 非功能需求

- 继承 V1.0 NFR。
- 批量导入须有明确进度/完成反馈；大文件拒绝时提示不超过 10MB。
- 目录列表滚动加载不得导致筛选条件丢失。
- 后端与迁移遵循 DEC-WSC-005 与 backend / migration Skill。
