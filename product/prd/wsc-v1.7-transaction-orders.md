## 问题与目标

### 要解决的问题

工作台此前仅将「交易订单」作为壳层占位，无法在平台内完成数据产品订购过程的记录与回溯。需求方、提供方和管理员缺少统一入口查看订单状态、时间线与合约进展。本期打通**链内一事一议简易流程**：从订购创建到合约达成（或取消），订单过程可追踪。本期**不承担**支付、结算、发票、交付、履约和售后。

### 成功标准（可观察）

本期成功指标为 **订单可追踪率**（产品填写，补充项 20）：

1. 每一笔平台内创建的订单，从创建到当前状态均可在详情中看到对应时间线。
2. 创建、确认订单、提交合约与交易信息、确认合约、取消等状态变更，均能看到对应 mock 上链记录。
3. 详情产品区始终为下单时快照，不随产品最新内容漂移。
4. 角色菜单、列表范围与可执行动作符合下文角色表；无权限动作不可见、不可用。
5. 主流程可走通：待确认订单 → 待上传合约 → 待确认合约 → 合约已达成；未完成三态可取消至已取消且不可回退。
6. V1.6 已确认能力不得回退。

## 角色与权限

| 角色 | 菜单名称 | 列表可见范围 | 可执行动作 |
|---|---|---|---|
| USER | 我的订单 | 仅本人作为需求方提交的订单 | 发起链内订购；查看本人订单；待上传合约时提交合约和交易信息；三个未完成状态可取消本人订单 |
| PROVIDER | 交易订单 | **仅当前企业作为提供方的订单** | 对本企业订单：确认订单、确认合约、取消；不可代替其他企业操作 |
| ADMIN | 交易订单 | 平台全部订单 | **仅管理员**可代替提供方：确认订单、确认合约、取消订单；可查看全部 |

补充（产品已确认）：

- 管理员代操作仅限管理员角色；提供方不能代其他企业操作。
- 敏感字段按角色脱敏后展示（见 REQ-WSC-ORDER-008 / 约束）。
- 同一企业多名用户之间的订单共享、协作和转交本期不展开。
- 隐藏菜单不等于授权：深链与写操作须按上表校验。

2. 链内简易流程：创建订单、状态流转、角色动作、取消。本期只实现**平台内创建订单**。

4. 订单详情：产品**下单快照**、状态进度、时间线、上链展示（**mock**）、数字合约（按主数据带入，变更生成新版本）。
5. 一事一议：模板下载、在线填写交易信息、**签署附件为主**（Word/PDF，单文件，不超过 20MB）。
6. **统一合约确认页**（合并原 Demo 标准合约弹窗与一事一议确认）。
7. 订购须知使用**平台统一须知**；提交链内订购前须勾选。

- 通知、待办、催办和处理时限。
- 真实上链、上链失败补偿（本期 mock；不因真实链失败阻断演示状态推进）。
- 支付、退款、分账、发票、对账、交付、履约、售后。本期止于**合约达成**。
- 列表导出、批量操作、日期范围筛选。
- 合同司法效力、电子签章平台对接细则（签署附件作为正文来源，不扩展签章产品）。
- 同一企业内订单共享、协作、转交。
- 企业管理页、超管/企管菜单拆分（继承 V1.6 Out of Scope）。

## 端到端流程（正式规则）

交互步骤可参考 Demo；下列边界以产品填写为准。

### 1. 外部平台跳转（非建单）

1. 普通用户可从产品详情或订购入口发起订购，查看本次产品和订购方信息。
2. 用户可选择前往来源平台完成订购（若保留该入口）。
3. 有配置地址则尝试打开；无地址则提示未配置。
4. **不创建本地订单，也不接收外部推送建单**。

### 2. 链内一事一议简易流程（本期实现）

1. **仅当产品标记为允许链内简易流程时**，普通用户可选择该方式。
2. 需求方填写订购备注，并勾选同意《数据产品订购须知》（平台统一须知）。备注为空不能提交。
3. 提交后创建待确认订单；写入产品快照；展示时间线与订单创建 mock 上链记录。
4. 提供方确认本企业订单（管理员可代确认），状态变为待上传合约。
5. 需求方本人下载模板，在线填写交易信息，上传一份符合规则的签署附件（正式正文）。无合格附件不可进入待确认合约。
6. 需求方提交后，状态变为待确认合约，并新增时间线与 mock 上链记录。
7. 提供方（或管理员代操作）在**统一合约确认页**核查交易信息、平台统一须知与签署附件，勾选后确认达成。
8. 状态变为合约已达成，并新增时间线与 mock 上链记录。本期主流程在此结束。
9. 三个未完成状态可由需求方、提供方、管理员取消（须二次确认），进入已取消；取消后不可回退。

## 状态机

主流程：`待确认订单 → 待上传合约 → 待确认合约 → 合约已达成`

| 当前状态 | 代码名（交互参考） | 可执行角色 | 动作 | 下一状态 | 上链展示 |
|---|---|---|---|---|---|
| 待确认订单 | `pending` | 提供方（本企业订单）；管理员（可代操作） | 确认订单 | 待上传合约 | mock 记录 |
| 待上传合约 | `confirmed` | 订单需求方本人 | 上传合约并补充交易信息 | 待确认合约 | mock 记录 |
| 待确认合约 | `negotiating` | 提供方（本企业订单）；管理员（可代操作） | 确认合约（统一确认页） | 合约已达成 | mock 记录 |
| 合约已达成 | `completed` | 无后续主流程动作 | 无 | 终态 | 到达时已写入 |
| 待确认订单、待上传合约或待确认合约 | 同上 | **需求方、提供方、管理员（三方）** | 取消订单（须二次确认） | 已取消 | mock 记录 |
| 已取消 | `cancelled` | 无 | 无 | 旁路终态 | 到达时已写入 |

规则：

- 已取消为旁路终态，**不回退**。
- **状态不可回退**。不增加拒绝、退回、撤回、超时状态。
- 上链为 **mock**。实现时业务状态与 mock 记录一并写入；本期不因真实链失败阻断状态推进。
- 列表状态筛选项与上表页面名称对齐：全部、待确认订单、待上传合约、待确认合约、合约已达成、已取消。Demo 中「已确认 / 待合约确认」等叫法仅作参考，正式文案以上表为准。

## 订单列表与详情（产品确认）

### 列表

- 搜索：订单号、产品名称、产品编码、需求方姓名、需求方单位。
- 状态筛选：见状态机。
- 无匹配时显示「暂无订单数据」。

- **仅分页**：须支持页码输入跳转和更换每页条数。档位默认 10 / 20 / 50 / 100，缺省 10；更换 pageSize 后回到第 1 页。与 `RULE-GLOBAL-FRONTEND` 及现有目录维护分页约定一致。不导出、不批量、无日期范围筛选。
- 隐私字段按角色脱敏后展示。

列表展示字段（九组 + 操作）：

| 字段 | 内容 |
|---|---|
| 订单号 | 订单唯一标识 |
| 产品信息 | 产品名称、产品编码、产品类型、来源平台 |
| 提供方 | 提供方名称 |
| 需求方 | 订购人姓名、用户名、所属单位 |
| 金额 | 填写交易信息后计算的金额（创建初期可为空或占位，以产品确认的计费规则为准） |

| 上链次数 | 当前订单已展示的 mock 上链记录数量 |

| 操作 | 查看 |

### 详情

- 布局可参考 Demo 左右分区，**不以 Demo 字段堆砌为验收全集**。
- 产品区**始终使用下单时快照**，不跟随产品最新内容。
- 须能展示：产品快照、状态进度、订单基本信息、订购方、合约/签署附件、一事一议交易信息、时间线、mock 上链信息、数字合约版本。
- 标题含订单号；可返回列表。
- 正式合约正文为**签署附件**；在线文本可作为辅助，不能替代附件。
- 附件下载按角色限制。
- 数字合约字段**按主数据自动带入**；每次订单/合约相关变更生成**新版本**并保留历史。无主数据时按空值/占位展示，不阻断本期下单。

## 合约、金额、附件与脱敏

### 附件（补充项 5）

| 项 | 规则 |
|---|---|
| 格式 | Word、PDF（白名单） |
| 大小 | 单个不超过 20MB |
| 数量 | 一份 |
| 存储期限 | 无上限 |
| 安全 | 白名单校验 + 病毒扫描 |
| 下载 | 按角色限制 |

未上传符合规则的签署附件时，不可进入待确认合约。

### 金额（补充项 6）

- 币种：人民币。
- 精度：两位小数。
- 含税价与未税价本期**使用同一价格**；数据上**同时保留含税、未税两个字段**，便于后续拆分。
- 在线计费信息仍须填写。单价须大于零；缺少单位或数量不能提交；明细与小计须正确。计费模式交互可参考 Demo，**不以 Demo 示例金额为规则**。

### 脱敏（补充项 9）

按角色脱敏展示：姓名、用户名、单位、信用代码、连接器标识、合约正文等敏感字段。掩码细则与目录敏感字段策略对齐（见开放问题 OQ-V17-001，不阻塞本期范围裁定）。

### 统一合约确认页（补充项 11）

原「标准合约弹窗」与一事一议确认合并为**同一确认页**：展示交易信息、平台统一须知、签署附件（可下载，受角色限制）；勾选确认后达成合约。未勾选不能确认。

### REQ-WSC-ORDER-001 角色化订单菜单与数据范围

- **优先级**：P0
- **变更**：新增；取代壳层「交易订单」占位未开放
- **摘要**：USER 见「我的订单」且仅本人作为需求方的订单；PROVIDER 见「交易订单」且仅当前企业作为提供方的订单；ADMIN 见「交易订单」且可看全部，并可代提供方确认订单、确认合约、取消。
- **验收**：
  - USER 菜单和列表标题为「我的订单」，看不到他人作为需求方的订单；
  - PROVIDER 看不到其他企业作为提供方的订单，不能代其他企业操作；
  - ADMIN 可查看任意企业订单，并可执行代确认订单、代确认合约、代取消；
  - USER 不可见 PROVIDER/ADMIN 的「交易订单」菜单文案混用导致范围误解；深链无权限时不可达或明确拒绝；
  - 侧栏原「本版本未开放」占位对交易订单不再出现（USER/PROVIDER/ADMIN 进入对应真实列表）。

### REQ-WSC-ORDER-009 订单详情分区

- **优先级**：P0
- **摘要**：详情展示产品快照、订单、参与方、合约附件、时间线、mock 上链、数字合约版本。
- **验收**：标题含订单号；可返回列表；产品区为快照而非最新产品；上述分区信息可被对应角色查看（受脱敏与下载限制）。

### REQ-WSC-ORDER-010 链内主状态流转

- **优先级**：P0
- **摘要**：四步主流程，状态不可回退，本期止于合约达成。
- **验收**：
  - 确认订单后为待上传合约；
  - 需求方提交合格附件与交易信息后为待确认合约；
  - 统一确认页确认后为合约已达成；
  - 界面与数据均不能回退到上一状态；
  - 合约已达成后无支付/交付等后续主流程动作。

### REQ-WSC-ORDER-011 状态动作权限

- **优先级**：P0
- **摘要**：确认订单 / 确认合约：提供方对本企业订单，管理员可代操作。上传合约：仅需求方本人。取消：三方均可（未完成状态）。
- **验收**：不满足条件不显示对应按钮；越权提交被拒绝且状态不变。

### REQ-WSC-ORDER-012 取消订单旁路

- **优先级**：P0
- **摘要**：三方均可在三个未完成状态取消；须二次确认；不可回退。无需对方同意。
- **验收**：
  - 待确认订单、待上传合约、待确认合约可取消；合约已达成与已取消不可再取消；
  - 须先弹出二次确认，用户取消确认则不发请求、状态不变（`RULE-GLOBAL-FRONTEND` §2）；
  - 确认后状态为已取消；时间线与 mock 上链有取消记录；无主流程后续动作。

### REQ-WSC-ORDER-013 签署附件与交易信息

- **优先级**：P0
- **摘要**：须上传一份 Word 或 PDF 签署附件（≤20MB，白名单 + 病毒扫描）；在线计费信息仍要填写；正文以附件为准。
- **验收**：
  - 无合格附件不能提交进入待确认合约；
  - 非白名单格式或超过 20MB 不能作为合格附件；
  - 详情可按角色下载；存储不设期限；
  - 在线文本不能替代签署附件。

### REQ-WSC-ORDER-014 计费信息与金额

- **优先级**：P0
- **摘要**：金额人民币两位小数；含税与未税本期同值，同时保留两个字段。
- **验收**：单价大于零；缺单位或数量不能提交；明细与小计正确；展示与计算为人民币两位小数；含税与未税本期同价。

### REQ-WSC-ORDER-015 统一合约确认页

- **优先级**：P0
- **摘要**：提供方或管理员在统一页核查交易信息、须知与签署附件后确认达成。不保留独立「标准合约弹窗」作为另一套确认路径。
- **验收**：页内可见交易信息、平台统一须知、签署附件（下载受角色限制）；未勾选不能确认；确认后状态为合约已达成；写成功 toast。

### REQ-WSC-ORDER-016 时间线与 mock 上链

- **优先级**：P0
- **摘要**：创建及每次状态变更写时间线与 mock 上链展示。
- **验收**：
  - 创建、确认订单、提交合约、确认合约、取消均有时间线与 mock 上链记录；
  - 列表上链次数与详情记录数一致；
  - 展示字段可含交易哈希、区块高度、时间、区块哈希等，来源为模拟适配器；
  - 不依赖真实链网；本期不以真实上链成败作为状态推进条件。

### REQ-WSC-ORDER-017 数字合约版本

- **优先级**：P1
- **摘要**：按主数据带入字段；每次相关变更生成新版本并保留历史。
- **验收**：下单时有初版；详情可看到当前版本；订单/合约相关变更后版本号或版本列表更新；无主数据字段空值/占位且不阻断下单。

### REQ-WSC-ORDER-FE-001 写接口成功 toast

- **优先级**：P0
- **依据**：`RULE-GLOBAL-FRONTEND` §1
- **摘要**：订单相关新增、修改、删除（含取消等状态变更）调用成功后须 toast 提示成功。
- **验收**：创建订单、确认订单、提交合约、确认合约、取消订单成功后出现成功提示；失败走既有错误提示，不出现成功 toast；只读查询成功不必 toast。

### REQ-WSC-ORDER-FE-002 重要操作二次确认

- **优先级**：P0
- **依据**：`RULE-GLOBAL-FRONTEND` §2
- **摘要**：删除、禁用、取消等不易撤销的操作，提交前须二次确认。
- **验收**：取消订单必须先弹出确认，用户确认后才发请求；未确认则不改变订单状态；若本模块后续出现删除或禁用类动作，同样需要二次确认。

### REQ-WSC-ORDER-FE-003 分页页码与 pageSize

- **优先级**：P0
- **依据**：`RULE-GLOBAL-FRONTEND` §3
- **摘要**：订单列表分页须支持页码输入跳转和更换每页条数。
- **验收**：可输入页码跳转；可更换 pageSize 并重新拉取列表；更换后回到第 1 页；仅翻页不改变 pageSize。

### REQ-SHELL-011 导航：开放交易订单 / 我的订单

- **优先级**：P0
- **变更**：修订 REQ-SHELL-001 占位策略；V1.6 REQ-SHELL-009 目录子菜单保持不变
- **摘要**：按角色开放订单入口；目录相关菜单继承 V1.6。
- **验收**：
  - USER 侧栏可见「我的订单」并进入本人订单列表；
  - PROVIDER、ADMIN 侧栏可见「交易订单」并进入各自范围列表；
  - V1.6「数据目录」收纳、我的目录 / 目录维护 / 我的数据产品可见性不回退。

## 约束

- 契约目标：`wsc-contracts@2.3.2`（本版订单能力按增量演进，不得削弱已发布目录契约语义）。
- 前端交互底线：`RULE-GLOBAL-FRONTEND`；与其他模块冲突时以该规则为准并复用同一组件。
- 状态机最小集，禁止擅自增加拒绝/退回/撤回/超时态。
- 上链 mock，禁止把真实链网可用性当作本期发布门禁。
- 附件白名单 + 病毒扫描 + 角色下载限制为产品要求；扫描落地方式见 OQ-V17-002。
- 金额人民币、两位小数；含税未税同价双字段。
- 产品快照冻结；数字合约按主数据带入、变更出新版本。
- 不编写、不依赖 Demo 随机哈希与示例企业作为验收数据。
