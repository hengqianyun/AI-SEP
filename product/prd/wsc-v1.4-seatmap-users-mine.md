# 接入端工作台（WSC）V1.4 — 流通链座序图 / 用户管理 / 我的数据产品

| 项 | 内容 |
|---|---|
| 版本 | V1.4 |
| 适用主体 | 可信数据空间接入端运营方 / 数据提供方 |
| 状态 | DRAFT→实现中 |
| 上游基线 | SNAP-WSC-004（功能）+ SNAP-WSC-003（UX） |
| 契约目标 | `wsc-contracts@2.2.0` |

## 业务目标

1. 在公共「数据目录」展示「数据流通链」座序图：二级目录按产品数 Top5，比例渲染座位，悬停熄灭其它域。
2. 持久化用户账号（`sys_user`），管理员可创建账号并配置角色，支撑真登录。
3. 新增「我的数据产品」（仅数据提供方）：布局同数据目录但无座序图，承载新增/编辑/批量导入；公共数据目录取消增改导。管理员保留分类维护与目录维护。

## 角色与权限

| 角色 | 能力 |
|---|---|
| 管理员 | 浏览+座序图；分类维护；目录维护；用户管理；**无**产品增改导 |
| 提供方 | 浏览+座序图；我的数据产品（本人产品增改导） |
| 普通用户 | 浏览+座序图；只读 |

## Out of Scope

- Downloads React 仓改造
- 密码重置邮件 / OAuth / 多租户
- 座序图点击联动 L2 筛选
