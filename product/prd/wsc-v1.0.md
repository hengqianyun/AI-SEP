## 问题与目标

- 要解决的问题：接入端缺少统一工作台，运营与数据提供方无法直观掌握链上资产运营态势，也难以对数据产品目录进行结构化登记、检索、详情查看与上链溯源。
- 成功标准：
  - P0 路径（登录身份切换 → 总览查看 → 数据目录筛选/检索 → 产品详情 → 上链信息 → 新增/编辑产品并产生链上版本）在 staging 端到端通过；
  - 管理员可维护行业一二级分类；提供方可新增/编辑产品；普通用户仅可浏览；
  - P0 缺陷为 0。

## 范围

### In Scope

- Web 接入端工作台（左侧导航 + 主内容区）
- 角色视图：管理员、提供方、普通用户（权限差异见下方）
- **总览**：核心运营指标、增长趋势、上链 TOP、最新上链流、行业/地域分布
- **数据目录**：行业索引、多维筛选与搜索、产品列表/预览、产品详情、新增/编辑、行业分类维护
- **上链信息**：按产品查看版本化存证与权属证书快照
- 产品类型差异化字段：数据集 / 数据报告 / 数据接口（及其他数据产品基础信息）

### Out of Scope / 非目标

- **数据登记**完整业务流（菜单占位，本版不交付页面与接口）
- **交易订单**下单、履约、分账（仅总览流中可展示相关上链动态文案）
- **连接器管理**（菜单占位，本版不交付）
- 真实区块链节点接入与链上交易确认（本版可对接存证服务或先做可替换适配层；验收可用模拟哈希/DID）
- 移动端原生 App / 对外公开注册门户
- 多租户隔离与跨企业组织树管理
- 真实支付与计费结算引擎

## 系统角色

| 角色 | 能力 |
|---|---|
| 管理员（运营管理员） | 浏览总览与目录；维护行业一/二级分类；新增/编辑数据产品 |
| 提供方 | 浏览总览与目录；新增/编辑数据产品；不可维护行业分类 |
| 普通用户 | 浏览总览与目录、产品详情与上链信息；不可新增/编辑产品，不可维护分类 |

> 说明：原型以侧栏角色切换演示权限差异；正式实现应为登录态鉴权，禁止仅靠前端隐藏。

## 需求

### REQ-SHELL-001 工作台壳层与导航

- 优先级：P0
- 摘要：提供固定侧栏品牌区（接入端工作台）、主导航与当前企业信息区；主区按模块切换页面。
- 验收：
  - 侧栏展示「总览」「数据目录」；「数据登记」「交易订单」「连接器管理」可见但点击后明确提示「本版本未开放」或不进入空页误导；
  - 当前企业信息可展示（如接入企业名称）；
  - 角色切换（或登录后角色）后目录写操作入口按权限立即更新。

### REQ-RBAC-001 角色权限控制

- 优先级：P0
- 摘要：按角色控制「维护行业分类」「新增产品」「编辑产品」入口与对应写接口。
- 验收：
  - 管理员可见「维护行业分类」与「新增/编辑」；
  - 提供方可见「新增/编辑」，不可见分类维护；
  - 普通用户无上述写入口；直接调用写 API 返回 403。

### REQ-OVW-001 总览核心指标

- 优先级：P0
- 摘要：展示可信数据空间核心运营指标卡片。
- 验收：至少包含：
  - 链上数据资产总数（已登记并上链的数据条目数）；
  - 活跃节点 / 企业数；
  - 今日新增存证；
  - 页面展示最近更新时间。

### REQ-OVW-002 数据增长趋势

- 优先级：P0
- 摘要：展示近 30 天数据上链流量趋势图。
- 验收：横轴为日期、纵轴为上链量；无数据时有空态；窗口缩放不破坏图表可读性。

### REQ-OVW-003 产品上链次数 TOP10

- 优先级：P1
- 摘要：按产品展示上链次数排行（TOP10）。
- 验收：展示产品名与次数；排序正确；不足 10 条时按实际条数展示。

### REQ-OVW-004 最新上链记录流

- 优先级：P0
- 摘要：展示最近上链动态（默认最近 10 条），类型至少覆盖：目录登记、数据登记、交易订单。
- 验收：每条含类型、主体、动作摘要、相对时间、上链记录标识（哈希或等价 ID）；列表按时间倒序。

### REQ-OVW-005 资源分布

- 优先级：P1
- 摘要：展示行业分布与地域分布可视化。
- 验收：行业为占比类图表；地域为条形/柱状对比；数据合计与目录侧统计口径一致或有明确说明。

### REQ-CAT-001 数据目录浏览结构

- 优先级：P0
- 摘要：左侧行业一级索引 + 中部二级分类下产品列表 + 右侧产品预览。
- 验收：
  - 点击行业切换产品集；
  - 列表项展示序号、产品编码、产品名称、上链次数、产品类型标签；
  - 选中产品后右侧预览显示名称、编码、分类路径、上链次数、概述及操作按钮。

### REQ-CAT-002 多维筛选与搜索

- 优先级：P0
- 摘要：支持组合筛选与关键词搜索。
- 验收：支持以下条件（可多选组合，空表示全部）：
  - 行业分类：一级/二级级联；
  - 数据来源：自行生产 / 公开收集 / 协议取得 / 衍生创造；
  - 产品类型：数据集 / 数据报告 / 数据接口 / 其他数据产品；
  - 是否涉及公共数据：是 / 否；
  - 交付方式：API / 文件传输 / 数据沙箱 / 隐私保护计算；
  - 搜索：产品名、产品编码（包含匹配，大小写不敏感）；
  - 无结果时有明确空态文案。

### REQ-CAT-003 产品预览操作

- 优先级：P0
- 摘要：预览区可进入产品详情、上链信息；有写权限时可进入编辑。
- 验收：三个入口分别打开对应页面；普通用户不出现编辑按钮。

### REQ-CAT-004 产品详情只读页

- 优先级：P0
- 摘要：完整展示产品只读详情，分组呈现。
- 验收：至少包含以下分组与字段：

**基础信息**

| 字段 | 必填（登记时） | 说明 |
|---|---|---|
| 产品名称 | 是 | |
| 产品编码 | 是 | 全局唯一；见试点裁决 DEC-WSC-001 |
| 产品类型 | 是 | 数据集 / 数据报告 / 数据接口 / 其他数据产品 |
| 行业分类 | 是 | 如：卫生 |
| 业务大类 | 否 | 对应目录一级（医疗健康 / 工业制造 / 金融服务等） |
| 业务子类 | 否 | 对应目录二级 |
| 数据来源 | 是 | 见枚举 |
| 更新频率 | 否 | 实时 / 每日 / 每周 / 每月 / 每年 / 按需 |
| 交付方式 | 是 | 见枚举 |
| 涉及个人信息 | 是 | 是 / 否 |
| 涉及公共数据 | 是 | 是 / 否 |
| 计费方式 | 否 | 自由文本，如按用量、按订阅 |
| 价格 | 否 | 数值或「一事一议」 |

**供应商信息**：供应商名称（必填）、统一社会信用代码、供应商简介  

**数据产权信息**：数据产权登记证书编号；产权类型（数据持有权 / 数据使用权 / 数据经营权）  

**类型专属信息**（按产品类型展示其一）：

- 数据集：地域范围、时间范围、数据量、数据格式、字段数量、数据质量等级（A–D）
- 数据报告：报告周期、报告格式、分析维度、地域范围、时间范围、数据来源描述、报告发布时间
- 数据接口：API 端点、请求方法、响应格式、限流、文档 URL、鉴权方式、API 版本

**关键标签**、**产品简介**、**应用场景**

- 有写权限时详情页提供「编辑」入口。

### REQ-CAT-005 新增 / 编辑数据产品

- 优先级：P0
- 摘要：管理员与提供方可登记或更新数据产品；提交后进入目录且生成链上版本记录。
- 验收：
  - 未填产品名称或产品编码时阻止提交并提示；
  - 切换产品类型时动态切换类型专属字段区；
  - 标签支持输入后回车添加、可删除；
  - 新建成功：状态为已上架（或等价默认态），并产生第 1 版上链记录；
  - 编辑成功：字段更新，并追加新版本上链记录（版本号递增）；
  - 取消/返回不保存变更。

### REQ-CAT-006 维护行业分类

- 优先级：P0
- 摘要：管理员维护一级、二级行业分类（增删改/排序以原型能力为准）。
- 验收：
  - 弹窗左右栏分别维护一级、二级；
  - 支持新增一级/二级；有未保存变更时有「待保存」提示；
  - 保存后目录索引与筛选级联数据更新；取消不落库；
  - 非管理员不可打开维护入口；有挂载产品的分类禁止删除（DEC-WSC-003）。

### REQ-CHAIN-001 上链信息页

- 优先级：P0
- 摘要：按产品查看上链记录列表与选中版本的目录快照。
- 验收：
  - 左侧为上链记录列表（版本号 + 时间），默认最新优先；
  - 每条记录含「存证上链」：元数据哈希、权属 DID、时间戳；「权属证书」：权属方、时间戳；
  - 右侧展示对应版本的产品目录上链详情快照；
  - 无记录时有空态。

## 非功能需求

- 页面以中文为主；关键操作有明确成功/失败反馈。
- 列表与筛选在常见桌面分辨率可用；图表在窗口变化时可重绘。
- 写操作需鉴权；敏感标识（哈希、DID、信用代码）按展示规范截断或完整复制（本版至少完整可读）。
- 上链适配层可替换：本版允许模拟存证，但数据结构需预留 metadataHash / ownerDID / timestamp / certificate.owner。
