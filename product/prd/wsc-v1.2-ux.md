## 问题与目标

- **要解决的问题**：当前 Vue 实现（`frontend/`）的界面布局、视觉层次、组件样式与交互细节，与已入库的 V1.1 HTML 原型 [`design/prototypes/wsc-v1.1/index.html`](../../design/prototypes/wsc-v1.1/index.html) **相差甚远**，影响可感知完成度与验收对照。
- **成功标准**：
  - 主路径页面（登录、壳层/侧栏、总览、数据目录、目录维护、分类维护弹窗、产品详情/编辑、批量导入、上链信息等）在**信息架构与视觉呈现**上与原型对齐到可验收程度；
  - V1.1 已交付功能行为（RBAC、三级分类、导入、上链等）**不回退**；
  - 不以「另起一套视觉」替代原型；原型为 UI/UX 对照权威，功能契约仍以 `wsc-contracts@2.0.0` + SNAP-WSC-002 为准（本版仅增量 UX REQ）。

## 相对 V1.1（功能基线）的变更摘要

| 类型 | 内容 |
|---|---|
| 新增 | 独立 UX 对齐需求包：设计令牌、壳层/页面视觉与交互打磨、与原型偏差清单闭环 |
| 变更 | 前端表现层（布局、间距、色彩、字体、卡片、表格、弹窗、空态/加载态、图表样式等）向原型收敛 |

## 范围

### In Scope

- 对照原型做**逐屏 UI/UX 差距**并落地到 `frontend/`（含全局样式 / 设计令牌 / 共享布局组件）
- 侧栏品牌区与导航视觉；主区背景与内容卡片层次
- 总览指标卡与图表样式对齐（在既有数据契约内）
- 数据目录：顶部标签、子类分组、列表/筛选区视觉与滚动加载呈现
- 目录维护、分类维护弹窗、批量导入弹窗的布局与控件样式
- 产品详情 / 编辑 / 上链信息页的视觉对齐
- 登录页与角色切换区的视觉一致性
- 响应式以桌面端为主（与原型一致）；明显破坏性窄屏问题可修
- 必要的前端单测 / 视觉回归抽样（由后续计划与 QA 定义）

### Out of Scope / 非目标

- 重做 V1.1 业务功能或重新打开已关闭的功能缺陷（除非本轮 UX 改造引入回归）
- 修改 `contracts/**`、后端写路径、Flyway/SQL（默认）
- 移动端原生 App、暗色主题（原型未要求则不做）
- 用 Ant Design 默认主题「凑合」而未对照原型令牌与布局
- 替换图表库若非对齐所必需（优先 CSS/配置级对齐）

## 系统角色

与 V1.1 相同（管理员 / 提供方 / 普通用户）；本版**不改变**权限矩阵，只改变有权页面的呈现与交互质感。

## 需求（草案提纲 — 细则由 Product Analyst 落入 SNAP）

> 以下为 PO 意图提纲，**不是**已批准快照。正式 REQ ID / 验收句式由 `productAnalyst` 在 SNAP-WSC-003 中给出。

1. **设计令牌与全局样式**：色彩、圆角、阴影、字号阶梯与原型 `:root` 变量对齐可追踪。
2. **壳层**：侧栏宽度/背景/Logo 区/导航激活态与主区背景对齐原型。
3. **总览**：指标卡与图表视觉对齐。
4. **数据目录**：标签栏、分组、行样式、筛选条对齐。
5. **目录维护 / 分类弹窗 / 导入弹窗**：对话框结构、表格、按钮层级对齐。
6. **详情 / 编辑 / 上链**：只读与表单布局对齐。
7. **回归**：三角色关键路径功能不回退；E2E 或约定冒烟通过。

## 约束

- 视觉权威文件：`design/prototypes/wsc-v1.1/index.html`（可交互 HTML 原型）。
- 功能与契约权威：SNAP-WSC-002 + `wsc-contracts@2.0.0`（本 Run 不静默改写）。
- 开发与审查隔离；并行任务须写集可证明安全。
- 中文界面文案与原型/V1.1 产品用语保持一致。

## 开放问题（供分析阶段收敛）

1. 是否允许为对齐引入有限的全局 CSS / 设计令牌文件重构（推荐是）？
2. 与 Ant Design Vue 默认控件的冲突：以**覆写主题/局部样式**对齐原型，还是替换部分控件？
3. 视觉验收形式：对照截图清单 / Playwright 截图抽样 / 人工走查签字？
4. 是否需要独立 `TESTRUN-WSC-E2E-UX` 还是复用并扩展既有 E2E？

## 验收总则（产品侧）

- PO / UX 对照原型主路径走查，无 P0 级「完全不像原型」的页面。
- 功能回归：管理员/提供方/普通用户 V1.1 主路径可用。
- 发布仍走独立 Run 门禁（计划委员会 + 开发审查测试 + 必要 E2E + 人类批准）。
