# 项目实例化任务模板索引

本目录曾集中存放任务填写说明。现已改为与 `FRONTEND-TEMPLATE.md` 相同模式：

**填写模板放在各交付物旁**（Skill 目录的 `TEMPLATE.md`、Rule 旁的 `*-TEMPLATE.md` 等）。

权威入口：[`PROJECT-CUSTOMIZATION-ASSIGNMENTS.md`](../PROJECT-CUSTOMIZATION-ASSIGNMENTS.md) 的 **Template** 列（直达对应模板文件）。

本目录下的 `PRODUCT.md` / `FRONTEND.md` 等仍可作对照草稿，**以交付物旁 TEMPLATE 为准**。

| 类型 | 模板位置示例 |
|---|---|
| 前端实现 Skill | [`ai/skills/frontend-developer/FRONTEND-TEMPLATE.md`](../ai/skills/frontend-developer/FRONTEND-TEMPLATE.md) |
| 后端实现 Skill | [`ai/skills/backend-developer/TEMPLATE.md`](../ai/skills/backend-developer/TEMPLATE.md) |
| 其他 Skill | `ai/skills/<role>/TEMPLATE.md` |
| Org Rule | `ai/rules/organization/*-TEMPLATE.md` |
| Project Rule / 配置 | `ai/rules/project/*-TEMPLATE.md` / `OWNERS-TEMPLATE.yaml` 等 |
| 工作流策略 | [`ai/workflow/POLICIES-TEMPLATE.yaml`](../ai/workflow/POLICIES-TEMPLATE.yaml) |
| 产品 | [`product/GLOSSARY-TEMPLATE.md`](../product/GLOSSARY-TEMPLATE.md)、[`product/prd/PRD-TEMPLATE.md`](../product/prd/PRD-TEMPLATE.md) |

使用方式：打开 Template 列文件 → 复制结构到目标 `SKILL.md` / Rule / yaml → 替换占位符 → 复核后 `draft`→`active`。
