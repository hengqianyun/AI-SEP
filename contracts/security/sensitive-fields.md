# 敏感字段策略表引用（wsc-contracts@2.3.3）

> 权威来源：PLAN-WSC-1.1 §3.7 + PLAN-WSC-2.2 §3.5（导入报告白名单）+ PLAN-WSC-5.2 §3.1（用户口令）。  
> 本文件为契约侧引用副本。

| 字段 | 存储 | API 响应 | 日志 |
|---|---|---|---|
| 涉及个人信息（布尔/标记） | 允许 | 按权限返回 | 可记标记值 |
| 供应商信用代码 | 允许 | 有权限可读；最小化列表字段 | **禁止明文** |
| ownerDID / metadataHash | 允许（上链版本/快照） | CHAIN/详情按 REQ 完整可读 | **禁止明文**或仅记截断指纹 |
| 产品概述等一般字段 | 允许 | 按契约 | 可记 |
| 用户 `password` / `passwordHash` | 允许（单向哈希） | **禁止**出现在 list/get/create/update 响应 | **禁止明文口令** |
| 导入原始上传文件 | 临时；处理结束删除或 TTL≤24h | 不回显全文 | **禁止**记上传全文 |
| 导入错误报告行 | 允许（TTL≤24h） | 仅白名单：行号、产品编码、原因码/文案 | 同白名单；**禁止**回显完整信用代码、ownerDID、明文哈希 |

## 展示约定

哈希、DID、供应商信用代码等：完整可读；UI 可截断展示并提供**完整复制**。
